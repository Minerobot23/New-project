# Email signature: Cristhian Garcia

- `signature.html` is the HTML signature. It uses tables, inline styles, and Arial so it renders the same in classic Outlook (Word engine), new Outlook, Outlook on the web, and mobile.
- `signature.txt` is the plain-text fallback, used for plain-text messages and clients that don't accept HTML signatures.
- There are no images, tracking pixels, social icons, phone numbers, or addresses. Add a phone number or mailing address only once they exist.

Install it only after `cristhian@fluxlinesolutions.com` is live in Microsoft 365.

## Copying the signature

Rich-text copy is the most reliable method for every Outlook version:

1. Open `signature.html` in a browser (Chrome or Edge).
2. Select everything from "Cristhian Garcia" to "fluxlinesolutions.com" and copy it (Ctrl/Cmd + C).
3. Paste it into the Outlook signature editor as described below.

## New Outlook for Windows and Outlook on the web

1. Go to **Settings** (gear icon) → **Accounts** → **Signatures**.
2. Click **+ New signature** and name it `Fluxline`.
3. Paste the copied signature into the editor and click **Save**.
4. Under **Select default signatures**, choose `Fluxline` for **For new messages** and **For replies/forwards**, then save again.

## Classic Outlook for Windows

1. Go to **File** → **Options** → **Mail** → **Signatures…**
2. Click **New**, name it `Fluxline`, and paste into the **Edit signature** box.
3. Under **Choose default signature**, select the `cristhian@fluxlinesolutions.com` account. Set both **New messages** and **Replies/forwards** to `Fluxline`.
4. Click **OK**.

## Outlook for Mac

1. Go to **Outlook** → **Settings** → **Signatures**.
2. Click **+**, name it `Fluxline`, and paste the signature.
3. Under **Choose default signature**, select the account and pick `Fluxline` for new messages and replies/forwards.

## Outlook for iOS and Android

The mobile app supports simple signatures. Go to **Settings** → **Signature**, choose the account, and paste the contents of `signature.txt`.

## Checking it

Send a message to a personal address (for example, the Gmail backup account) and confirm:

- Both links open correctly.
- Line breaks are preserved.
- No extra blank lines appear.
